# AI-Teaching-Assistant

A course-support assistant that helps instructors prepare teaching materials, respond to student needs, and manage routine instructional communication.

---

## Accounting Case Game

An interactive, immersive accounting learning app built with Next.js 14, TypeScript, Tailwind, Framer Motion, and Zustand.

### Features

- **3 roles**: Junior Accountant, Audit Associate, Controller
- **4 company types**: Retail, SaaS, Manufacturing, High Tech
- **Visual-novel gameplay**: animated role avatars, typewriter narration, company scene backgrounds
- **Branching cases** with scoring, document review, and event interrupts
- **v1 case**: Month-End Close: Missing Accruals (4 stages, 100-pt scoring)

### Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
